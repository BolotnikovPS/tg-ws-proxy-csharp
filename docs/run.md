# Запуск и аргументы командной строки

[← Оглавление](README.md)

Единственный режим — web-only: HTTP-сервер поднимается всегда, панель и API живут в том же процессе, что и прокси. Консольного запуска без Web-части больше нет.

```bash
TGWS_CONFIG=/etc/tg-ws-proxy/config.json dotnet TgWsProxy.dll
```

Путь к файлу конфигурации задаётся **только** переменной окружения `TGWS_CONFIG`; без неё берётся `./config.json` в текущем каталоге. Аргументы командной строки не поддерживаются.

Любой аргумент (`--config`, `--port`, `--secret`, `--verbose`…) завершает работу с кодом `1` и подсказкой, какой ключ `config.json` соответствует старому флагу (например `--port` → `"mtproto.port"`, `--secret` → `"tokens"`); для `--config` подсказка — что путь задаётся переменной окружения `TGWS_CONFIG`.
